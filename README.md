# Vigilia

Forum simple en HTML, CSS et JavaScript, avec données enregistrées dans `localStorage`.

## Utilisation

Ouvrir `index.html` dans un navigateur moderne. Aucun serveur ni dépendance requis.

## Compte administrateur

Un compte admin peut être créé dans l’écran d’inscription avec le pseudo `admin`.
Il peut supprimer tous les messages.

Pour la démonstration, un jeu de données peut être initialisé automatiquement au premier chargement.
